# 📝 TodoX MERN

- **TodoX MERN** là ứng dụng **Quản lý công việc (Todo App)** được xây dựng bằng **MERN Stack (MongoDB, Express, React, Node.js)**, kết hợp **Tailwind CSS** và **shadcn/ui** để tạo giao diện hiện đại, responsive và dễ sử dụng.
- Ứng dụng hỗ trợ **CRUD** (thêm, sửa, xoá và quản lý danh sách công việc), **lọc theo trạng thái/thời gian**, **pagination**, **thống kê**, đồng thời đã được triển khai trên Render.


🔗 **Demo**: [TodoX MERN](https://todox-mern.onrender.com/)

---

## 🚀 Công nghệ sử dụng

- **Frontend**
  - ⚛️ [React](https://react.dev/) - UI library
  - 🎨 [Tailwind CSS 4](https://tailwindcss.com/) - CSS framework
  - 🧩 [shadcn/ui](https://ui.shadcn.com/) - UI components
  - 🔄 [Axios](https://axios-http.com/) - HTTP client

- **Backend**
  - 🌐 [Express.js](https://expressjs.com/) - Web framework
  - 🗄️ [MongoDB](https://www.mongodb.com/) & [Mongoose](https://mongoosejs.com/) - Database & ODM
  - 🔑 [dotenv](https://www.npmjs.com/package/dotenv) - Quản lý biến môi trường
  - 🔒 [CORS](https://www.npmjs.com/package/cors) - Cross-origin resource sharing

- **Deploy**
  - 🌍 [Render](https://render.com/) 

---

## 🚀 Tính năng

- ✅ **Thêm / sửa / xóa / đánh dấu hoàn thành** công việc (CRUD).
- 📋 **Hiển thị danh sách** công việc.
- 🔍 **Lọc theo trạng thái**: tất cả, đang làm, đã hoàn thành.
- ⏰ **Lọc theo thời gian**: hôm nay, tuần này, tháng này.
- 📄 **Pagination**: chia trang danh sách công việc.
- 📊 **Thống kê**: số lượng công việc đã hoàn thành và chưa hoàn thành.
- 📱 **Responsive UI**: dùng được trên điện thoại, tablet, laptop.
- 🌐 **Deploy miễn phí** trên Render.
